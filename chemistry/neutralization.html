化学原理与方程式 Chemistry Principles

化学方程式：
HCl + NaOH = NaCl + H₂O
离子方程式：
H⁺ + OH⁻ = H₂O
  • 旁观离子 (Spectator Ions)

    反应前后 Na⁺ 与 Cl⁻ 始终游离在溶液中，不参与结合，因此在离子方程式中约去。

  • 滴定突跃 (Titration Jump)

    在 19.8 mL → 20.2 mL 之间，仅增加两三滴 NaOH，pH 就从约 3.3 跃升至 10.7，这是由 pH = -lg c(H⁺) 的对数性质决定的。

动手探究任务 Guided Tasks

  1. 滴加 NaOH，观察微观视野中 H⁺ 减少、H₂O 增加而 Cl⁻ 不变。
  2. 到达或跨越 20.0 mL 中和点，在曲线上观察 pH 突跃与指示剂变色。
  3. 在上方「选择酸碱指示剂」中点击切换紫色石蕊或甲基橙，对比它们的变色区间。
